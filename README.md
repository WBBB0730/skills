# skills

我的 agent skill 合集

## 安装

```bash
npx skills add WBBB0730/skills
```

只装指定的 skill：

```bash
npx skills add WBBB0730/skills --skill eli5
```

## Skill 列表

| Skill | 说明 |
| --- | --- |
| [eli5](skills/eli5/SKILL.md) | 让回复改用简洁的大白话，只讲重点，需要决定的事列出选项并给推荐。需手动调用（`/eli5`）；不带其他内容时重讲上一条回复，之后的回复都照此要求 |
